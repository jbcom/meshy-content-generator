# Security policy

Please report vulnerabilities privately through the [GitHub security advisory form](https://github.com/jbcom/meshy-content-generator/security/advisories/new). Do not create a public issue for a potential vulnerability and do not include credentials, tokens, customer data, or paid-generation artifacts in a report.

Include the affected version, a minimal reproduction, impact, affected operating environment, and any known mitigation. This project supports the latest published release line.

Meshy credentials, HTTP, retries, polling, downloads, and vendor error translation are owned by `vendor-fabric`; declarative pipeline expansion and ImageMagick post-processing are owned here. Reports spanning both will be coordinated privately.
